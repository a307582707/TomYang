# v0.1.0 发布说明（教材仓库）

**版本:** `v0.1.0`  
**日期:** 2026-07-28  
**维护者:** 上海海曦技术 / 仓库维护者

## 本版本含义

`v0.1.0` 标记 **TomYang 教材仓库** 的结构化基线，**不是**生产 Kubernetes 集群版本，**不**表示「可直接生产部署」。

| 并存内容 | 说明 |
|----------|------|
| **历史教材** | `k8s/` 控制面 1.11 时代清单，保留流程与参数组织参考 |
| **现代示例** | `examples/current/` 骨架（apps、ingress、networkpolicy、observability、security、runtime） |
| **归档隔离** | `k8s/archived/` + 静态检查，禁止 Dashboard/EFK/旧 metrics-server 等误用 |
| **文档与审计** | `docs/audits/`、`docs/MAINTENANCE.md`、Runbook、Wiki 长文（Wiki 为操作正文 SSOT） |

上游组件版本（apiserver `v1.11.1` 等）仍在 `docs/MAINTENANCE.md` 台账中单独记录，**不得**与仓库 SemVer 混读。

## 主要变更摘要（相对无 CHANGELOG 之前）

- **归档隔离：** `k8s/archived/` 迁入 Dashboard、EFK、metrics-server、WeaveScope 等；`scripts/check-archived-isolation.sh` 防推荐入口回流。
- **现代示例：** `examples/current/` 基线；`scripts/check-modern-examples.sh` 约束 API 与镜像标签。
- **静态检查：** `scripts/run-static-checks.sh` 聚合 YAML、密钥、危险模式、Wiki 链接等检查。
- **Wiki 结构：** 长文迁至 GitHub Wiki；本仓 `wiki/` 仅跟踪同步；INFRA-01 为搭建权威入口。
- **维护体系：** `docs/MAINTENANCE.md` 组件台账、季度复查脚本、审计索引 `docs/audits/README.md`。

## Git Tag 命令（维护者本地执行）

> **本 PR 不 push tag。** 合入主线且验收通过后，由维护者执行：

```bash
# 1. 确保在合入 v0.1.0 文档/CHANGELOG 的 master 提交上
git fetch origin
git checkout master
git pull --ff-only origin master

# 2. 核对 CHANGELOG [0.1.0] 日期与内容
git log -1 --oneline
git show HEAD:CHANGELOG.md | head -80

# 3. 创建附注 tag（仅当上述检查通过）
git tag -a v0.1.0 -m "$(cat <<'EOF'
TomYang v0.1.0 — textbook + modern examples baseline

Historical k8s/ manifests coexist with examples/current/;
archived isolation and static checks documented. Not a production deploy claim.
EOF
)"

# 4. 推送 tag（可选；按需发布）
git push origin v0.1.0

# 5. 若 tag 打错：删除本地/远程（谨慎）
# git tag -d v0.1.0
# git push origin :refs/tags/v0.1.0
```
